# Day 1 of #30DaysOfPython

Welcome to **Day 1** of the **#30DaysOfPython** challenge!

This Jupyter Notebook is part of a 30-day series where we explore Python programming from beginner to intermediate level. Day 1 focuses on foundational Python concepts to get you started.

## 📘 Topics Covered

- Printing text using `print()`
- Variables and assignment
- Data types: `str`, `int`, `float`, `bool`
- String concatenation and formatting
- Comments in Python
- Taking user input with `input()`
